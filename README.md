# 字幕校时台

纯前端 SRT 时间校正工具。整体平移或双锚点线性校时，检查全部字幕对重叠，导出 SRT、CSV、JSON 与 PNG。UTF-8 / 1MiB / 最多2000条；不上传字幕，不调用付费API。

## 本地运行
`node build.cjs` 构建单文件 index.html；用普通静态HTTP服务打开。`node --test tests/core.test.cjs` 运行核心测试。不需要安装依赖（封面生成脚本仅开发时使用sharp）。

## 计算边界
时间使用整数毫秒和 BigInt 有理数运算，最近毫秒舍入，半值远离零；不剪裁负时间和溢出。双锚点必须严格递增，倍率0.1–10；线性变速假设不适用于多段剪辑跳跃。输入只接受标准SRT数字序号/时间/非空文本；保留字幕原顺序与文字，重编号从1开始。CSV对公式开头文本防护，SRT原样保留。重叠只是提醒，不等于错误。

示例为虚构字幕，不代表实际音轨已经验证。工具不识别语音、不寻找锚点、不移除硬字幕。先在原视频确认锚点，再抽查输出。JSON可备份参数和原文，本机保存随站点数据清理而丢失。
